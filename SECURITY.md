# Security policy

## Supported versions

Security fixes are provided for the latest release. When practical, a fix may also be backported to another actively maintained release line.

## Reporting a vulnerability

Please do not disclose a suspected vulnerability in a public issue, discussion, or pull request.

Use the repository's **Security** tab and select **Report a vulnerability** to send a private report. If that option is unavailable, open a public issue containing no vulnerability details and ask the maintainer to establish a private contact channel.

Include the affected version, impact, reproduction steps, and any proposed mitigation. You should receive an acknowledgement within seven days. No guarantee can be made about resolution time, but confirmed reports will be handled according to severity and disclosed after a fix is available.

Dependency vulnerabilities can also be reported through the same private channel.
